# Асимптотика задач 13–24

| №  | *Задача*                             | **Время**  | **Память** |
|----|--------------------------------------|------------|------------|
| 13 | *Сортировка выбором*                 | `O(n²)`    | `O(1)`     |
| 14 | *Сортировка вставками*               | `O(n²)`    | `O(1)`     |
| 15 | *Пузырьковая с досрочным выходом*    | `O(n²)`    | `O(1)`     |
| 16 | *Сортировка по модулю*               | `O(n²)`    | `O(1)`     |
| 17 | *Сортировка по сумме цифр*           | `O(n²)`    | `O(1)`     |
| 18 | *Сортировка только чётных*           | `O(n + k²)`| `O(k)`     |
| 19 | *Слияние двух сортированных*         | `O(n + m)` | `O(n + m)` |
| 20 | *Сортировка подсчётом*               | `O(n + R)` | `O(R)`     |
| 21 | *K-й наименьший (полная сортировка)* | `O(n²)`    | `O(n)`     |
| 22 | *Сортировка по частоте*              | `O(n + u²)`| `O(u)`     |
| 23 | *Проверка анаграммы*                 | `O(n)`     | `O(u)`     |
| 24 | *Чётно-нечётная сортировка*          | `O(n²)`    | `O(1)`     |

**Обозначения:**
- *n*, *m* — размеры массивов (задача 19)
- *k* — число чётных элементов (задача 18)
- *R* — диапазон значений max − min + 1 (задача 20)
- *u* — число уникальных значений (задачи 22, 23)
